# braveslim

Brave bloated feature remover, make your browser more efficient.

## Prerequisite

Make sure you have `curl` installed on your system.

```sh
# debian, ubuntu, mint
sudo apt install curl

# arch, manjaro
sudo pacman -S curl

# fedora, red hat
sudo dnf install curl
```

## Usage

Just copy and paste the following command into your terminal:

```sh
curl https://raw.githubusercontent.com/fiandev/braveslim/refs/heads/master/main.sh | sh
```
